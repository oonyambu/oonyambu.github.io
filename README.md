# oonyambu.github.io

Personal academic portfolio of Samuel Onyambu, built with [Quarto](https://quarto.org).

- Source: the `.qmd` files and `_quarto.yml` at the repo root.
- Publishing: GitHub Pages serves the `master` branch root. Run `./publish.ps1`
  (or `quarto render` then copy `_site/*` to the root) and push.
- `statistics/` holds separately rendered teaching materials and is not part of
  the Quarto project; leave it in place so its URLs keep working.
